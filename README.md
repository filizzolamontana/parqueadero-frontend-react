\# Sistema de Gestión de Parqueadero - Front-end React



\## Descripción



Aplicación web desarrollada con React para la gestión de un sistema de parqueadero.



El proyecto corresponde al componente Front-end y consume servicios REST desarrollados previamente con Spring Boot.



\## Tecnologías utilizadas



\- React

\- Vite

\- JavaScript

\- Axios

\- HTML5

\- CSS3

\- Spring Boot

\- MySQL



\## Arquitectura



React → Axios → Spring Boot → MySQL



\## Funcionalidades



\- Inicio de sesión

\- Panel de control

\- Ingreso de vehículos

\- Consulta de registros

\- Creación de registros

\- Edición de registros

\- Eliminación de registros

\- Control de pagos

\- Reportes



\## Comunicación con el Back-end



La aplicación utiliza Axios para realizar peticiones HTTP al servicio REST desarrollado en Spring Boot.



Endpoint principal:



`http://localhost:8081/api/registros`



Operaciones implementadas:



\- GET

\- POST

\- PUT

\- DELETE
